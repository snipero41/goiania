# Goiania for Live for Speed (code `GN`)

Autodromo Internacional de Goiania, converted from Assetto Corsa to **Live for Speed** with lfs-track-builder, for lfs-custom-track.

## Install

You need the **S3 licence** and lfs-custom-track's **`dsound.dll`** next to `LFS.exe` (from the lfs-custom-track Discord downloads channel).

### Option A: Get mods (recommended, gets updates)

1. Open `mods\repositories.txt` in your LFS folder (next to `LFS.exe`, e.g. `C:\LFS\mods\repositories.txt`). It already exists and has a line `lfs-tracks`: leave it. Add a new line below it with my GitHub username: `snipero41` (every track of mine), or `snipero41/goiania` (only this track).
2. Restart LFS, open the track selector and press **Get mods**: **Goiania** will be there. Updates show up there too.

### Option B: by hand

Download `goiania.zip` from **Releases** and extract it into the `mods\tracks\` folder of your LFS folder (it contains the folder `goiania`). Restart LFS.

### Online

Host on *Layout Square* and put the code in the host name, e.g. `[GN] My server`. Every player needs the track installed.
